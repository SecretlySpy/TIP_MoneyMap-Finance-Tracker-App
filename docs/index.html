Quick start

  1. Install Node.js 22 LTS, JDK 21, Android SDK (API 35 recommended).
  2. npm ci
  3. Copy .env.example → .env (optional GEMINI_API_KEY).
  4. npm test (~91 tests)
  5. Start emulator/device, then npm run android (dev client required — Expo Go unsupported).

Architecture

  • Screens → Zustand stores → repositories → SQLCipher
  • Money is always integer minor units
  • Theme tokens only — no hardcoded hex in screens
  • Only src/remote/smartTipsClient.js may call remote fetch

Smart Tips privacy

  • Default off. First enable shows a consent sheet.
  • Offline: rules from local budgets/transactions.
  • Online: anonymized summary only (period, totals, category ratios, currency).
  • Never: raw transactions, notes, account names/IDs.
