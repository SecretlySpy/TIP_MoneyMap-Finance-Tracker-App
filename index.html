Overview

MoneyMap is a student-focused finance tracker that keeps ledgers on-device. Data lives in an encrypted SQLCipher database. Networking is limited to optional Smart Tips (Gemini) behind an explicit consent gate.

Setup

Shared flow after toolchain install: clone → npm ci → .env → emulator → npm run android.

1. Node 22 (nvm-windows or installer)

# nvm-windows, then:
nvm install 22
nvm use 22
node -v   # expect v22.x

2. JDK 21

Install Temurin 21. Set JAVA_HOME to the JDK 21 root (not a JRE). Confirm:

java -version
# openjdk version "21.x.x"

3. Android SDK

  1. Install Android Studio or command-line tools.
  2. SDK Manager: Platform 35, Build-Tools 35, Platform-Tools, NDK 27.1.12297006, CMake 3.22.1, Emulator, system-images;android-35;google_apis;x86_64.
  3. Enable WHPX / virtualization; verify with emulator -accel-check.
  4. Create AVD MoneyMap_VSCode_API_35 (Pixel 6 / Google APIs x86_64).
# Environment (User or System)
setx ANDROID_HOME "%LOCALAPPDATA%\Android\Sdk"
# Add %ANDROID_HOME%\platform-tools and emulator to PATH

cd TIP_MoneyMap-Finance-Tracker-App
npm ci
copy .env.example .env
# Optional: set GEMINI_API_KEY for online Smart Tips

5. Emulator + run

# Start AVD from Device Manager, or:
emulator -avd MoneyMap_VSCode_API_35

Troubleshooting

Expo Go unsupported / SQLCipher native module missing

Expo Go cannot load OP-SQLite + SQLCipher. Use a development client:

npm run android
# or EAS: eas build --profile development --platform android

After installing the APK, start Metro with npm start and open the app from the device.

Port 8081 in use → use 8082 + adb reverse 
npx expo start --dev-client --port 8082
adb reverse tcp:8082 tcp:8082
# In the dev client, connect to the listed host:8082 URL
Java 25+ breaks Gradle → use JDK 21

This Expo 54 / AGP stack is validated on JDK 21. Java 25+ fails configuration or compilation.

java -version    # must show 21.x
echo $JAVA_HOME  # must point at JDK 21

On Linux, prefer the user-space Temurin path under ~/.local/share/MoneyMap/toolchains/temurin-21.

Metro not connecting to the device / emulator
  • Confirm USB debugging or that the emulator is device in adb devices.
  • adb reverse tcp:8081 tcp:8081 (or your Metro port).
  • Same LAN for physical devices; disable VPN if it blocks local traffic.
  • Reload: shake device → Reload, or r in the Metro terminal.
Gradle download failures / flaky dependencies
  • Retry with a stable network; corporate proxies may need gradle.properties proxy settings.
  • Clear caches if corrupted: delete project android/ (CNG regenerates) and re-run npm run android.
  • Ensure disk space for SDK + Gradle caches under ~/.gradle.
Biometrics / SecureStore changes need a rebuild

Native module or config plugin changes (biometrics, notifications, SQLCipher flags) are not hot-reloaded. Rebuild the dev client:

npx expo prebuild --platform android --clean
npm run android
EAS projectId is still a placeholder

Release/cloud builds need a real EAS project. Run:

npm install --global eas-cli   # or npx eas-cli
eas login
eas init
# Replace the all-zero extra.eas.projectId in app config

Do not ship store builds with the placeholder ID.

Privacy & release

Smart Tips privacy

  • Default off. First enable shows a consent sheet.
  • Offline: deriveSmartTips from local budgets and transactions.
  • Online: anonymized summary only (period, totals, category ratios, currency) to Gemini.
  • Never sent: raw transactions, notes, account names or IDs.

Release

  • Package: com.moneymap.financetracker
  • Version: 0.1.0 (Tasks 1–18 complete)
  • Android automatic backup disabled (encrypted DB without Keystore key is unreadable)
  • Store credentials and Gemini keys in EAS Secrets — never commit .env
Before store upload Complete docs/release-checklist.md, align Play Data safety with docs/play-data-safety.md, and publish the privacy policy.
