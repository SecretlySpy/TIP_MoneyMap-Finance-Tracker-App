01

Overview

MoneyMap Finance Tracker is an Android-first personal finance tracker. It leverages React Native and Expo for its UI layer, and uses a local encrypted SQLCipher database for offline-first data storage.

Status Tasks 1 and 2 of the project plan are complete. The app features the strict Expo development-build shell, an encrypted SQLCipher database, atomic migrations, strict domain models, and the complete Figma UI replicated with high fidelity.
02

Prerequisites

Before attempting to run this project, ensure you have the following installed on your WindowsMacLinux machine:

  • Node.js 22 LTS
  • JDK 21
  • Android SDK with an API 34+ Google APIs x86_64 image

If you plan to develop, we recommend opening the repository in Visual Studio Code and accepting the recommended React Native Tools extension.

03

Installation

Clone the repository and install all Node dependencies.

# Clone the repository
git clone https://github.com/SecretlySpy/TIP_MoneyMap-Finance-Tracker-App.git
cd TIP_MoneyMap-Finance-Tracker-App

# Install dependencies
npm install
04

Run Locally

Because MoneyMap relies on native modules (specifically @op-engineering/op-sqlite), it cannot be run using Expo Go. You must compile it natively for Android.

Open your Android emulator via Android Studio Device Manager, then run: Open your Android emulator via Android Studio Device Manager (or run `emulator -avd [name]`), then run: Open your Android emulator via Android Studio Device Manager, then run: 

# Start the native build process
npm run android
Debugging Emulator Issues If you encounter an ADB connection error on Windows (e.g. Error: could not connect to TCP port 5554), you can restart the ADB server by running adb kill-server before attempting the build again.
